# Spectral Threshold｜频谱阈值

**一种关于「声音在暗处显形」的视觉哲学。**

光不需要照亮整个房间。它只需要在正确的位置切开黑暗，让轮廓自己浮现。这个运动相信：最有力的形状诞生于发光体与背景的交界处——那里既不是材料，也不是空无，而是一条被精确测量过的阈值。所有构图都从这条阈值开始，其余只是对它的克制回应。

形式必须可以被一眼读完，却值得长时间注视。它由重复的单元构成：等距、等宽、同一曲率，像一台仪器在记录某个不可见的量。重复不是装饰，而是度量——每一道单元的高度差都在陈述同一条斜坡，直到整组形状在负空间里组成第二个更大的符号。观者先看见节奏，再看见轮廓；先听见，再理解。

色彩只有两种职责：定义深度，标记能量。深色不是黑色，而是一层几乎察觉不到的暖紫，让发光体有地方可以呼吸。光色沿着一条从冷紫到粉红的窄带移动，绝不越界。饱和只出现在能量最高的那一端，其余部分保持低语。每一个色阶都经过手工校准，色带之间的过渡必须以像素为单位检查。

空间是神圣的。元素之间留出的距离不是剩余，而是设计本身。边距必须大到让人相信这是刻意为之，而对齐必须精确到让人找不到可以挪动的理由。任何一处拥挤都意味着整件作品失败。留白承担了至少一半的表达，因此它必须被当作实体来雕刻。

这件作品应当看起来像某个人在深夜反复推敲了数周：每一条曲线的圆角半径被单独验证，每一层辉光的衰减被逐帧比对，每一个色值在不同屏幕与不同缩放下被重新评估。它不能有半点「生成」的痕迹——只有大师级的、近乎偏执的手工感。最终它要小到可以成为一枚图标，大到可以挂进画廊，而两者看到的是同一个形状。
